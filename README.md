# Falling Meteors Reimagined for Forge 1.20.1

This repository hosts an unchanged copy of Falling Meteors Reimagined 2.5 for Forge 1.20.1, so the
SkyTekx3 modpack can download it from GitHub. The jar is attached to the
[latest release](https://github.com/skytekx/falling-meteors-reimagined/releases/latest).

Falling Meteors was written by AlexDGr8r for Hexxit. The Forge 1.20.1 port is by menoXD and is
published on [CurseForge](https://www.curseforge.com/projects/1489468).
The jar's `META-INF/mods.toml` declares the license "GNU LGPL v2.1 or later", and the jar is
redistributed here under that license, see [LICENSE](LICENSE).

The jar is byte for byte the file from CurseForge (project 1489468, file 8137833), 1,173,120 bytes,
SHA-1 a9d3117be3bc39120ee93b08352a9e1c8f54efd1. SkyTekx made no changes to it.

The source code of the port has not been published by its author, so SkyTekx does not hold it and
cannot pass it on. Questions about the source go to menoXD. If the author objects to this copy,
it will be taken down.
